**Built, the CLI half (`feat/e170-record-body-read`): `aew record body <id>` prints a record's body as written.** It answers for a work unit's record (the Ticket's, Story's or Epic's description) and for an evidence record (a report, a review, a research or discovery record, a plan proposal or assessment), current or archived: `aew history show` answers only for finished work and gives the body as an escaped string inside JSON. The engine's read is `HistoryCommands.record_body`, which reads through the accessors `work show` and `history show` use and checks what it returns the same way: a current evidence record against its seal and, once ingested, the hash its unit pins (`knowledge.evidence.locate` lists each unit's evidence and never builds a path from the id, and the record must name the one unit whose directory holds it); an archived one against its bundle (`held_evidence`); a unit's record against the hash control state pins. **As recorded, and safe to print:** line breaks, tabs and quotes are printed as they are; as recorded means with LF line endings and a final line break, which is how AEW stores a body. The body is an agent's or a person's text, so a character that could steer a terminal (an escape or OSC sequence, a carriage return, a C1 control, a bidi override) is printed visibly as `\uXXXX`, by `coordination.render.escaped`, the rule a worker's message is already shown under. **A limit of the text form:** invisible characters that steer nothing (zero-width and soft-hyphen characters, direction marks, line and paragraph separators, tag characters) are printed as they are, and the help says so. `escaped` is shared with worker messages and was not widened here, since that would change what another surface shows; `--json` shows every one of them as an escape. `--json` gives the exact text with the record's kind, unit, whether it is archived and, for evidence, whether the engine or a model wrote it; there is no other exact-bytes option, since no command has one. **Refusals:** `NOT_FOUND` with reason `unknown_record` (it says where ids come from) or `no_body` (an invocation, a credential, a history record of another kind, a unit created without a body, a check result; it names the read that has the fields), and `INTEGRITY_ERROR` for a record that is not what was recorded, each naming the file by its project path and saying what to do (for a current record, reason `not_text`, `not_sealed`, `unreadable`, `not_this_units`, `not_pinned`, `listed_twice` when two units list a record of that id, or `pinned_elsewhere` when the unit that pins it is not the one holding the file). **Who may read:** it takes no credential and no expected revision, and it grants nothing. It reads the project's own records under `.aew`: what `work show` and `history show` read, and a current unit's evidence, which lies beside them and which every reader of the project already sees. So it widens no reader: the Lead's session runs it locally (`lead_broker.CONTAINED_LOCAL`), and what a contained worker can read is decided by its sandbox, as for those reads; the command adds no check of its own and no way round one. **Why this name:** the designer's decision of 2026-10-06 gives `aew evidence show <id>` to the structured, bounded Evidence read, so this command leaves that name free. Tests: `tests/integration/test_record_body.py`, through the real CLI, and the surface map's probe, whose sample Ticket now has a body.

No typed tool is added here, so the Lead's tool count and its always-sent text are unchanged; `record body` prints a whole body, with no bound. **Found while building, not fixed here, now E399:** an evidence record whose body holds a lone carriage return is accepted at `submit` and then fails its own seal on every read; the review of #623 (m6) found that it also stops later `evidence ingest` and `work accept` on that unit. **Tracked from the quick check of #623 (q6):** the terminal-escaping rule `escaped` lives in `coordination/render.py`, the worker-message framing module, and `aew record body` imports that module for the one pure function; `test_legality_modules_never_import_coordination` names the importer and pins that it imports nothing else. Nothing breaks, but a later import added to `render` would reach this read. The fix moves `escaped` to a neutral module that both import and drops `aew/cli/history_commands.py` from the test's set; it is done by this row's next slice or by the first change that gives the rule another consumer, whichever comes first.
