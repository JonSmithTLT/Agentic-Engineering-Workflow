MS5b adds next-step and turn-end delivery to the coordination store. Both timings use the same durable recording
path as `harness send` when messaging is on. Recorded shell sends can still wake a held session. Worker waits take
next-step messages only. Existing runs must agree with the adopted messaging switch to accept a shell send.

Result ingests now check whether the submission incorporates the Lead messages recorded before it. A later message
appears as an advisory. `resume` and the read-only `aew message lost` recover messages that remained unadmitted after
an invocation ended. A new project registers and enables messaging at init. Existing projects with the key absent
may take the switch offer and explicit disabled settings are preserved.

This completes the implementation slice. MS7 real-provider qualification remains the operator's run.
