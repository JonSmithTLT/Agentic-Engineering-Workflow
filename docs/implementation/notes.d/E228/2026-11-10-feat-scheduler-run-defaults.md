**Built (`feat/scheduler-run-defaults`), the chain's third PR: what `RUN` needs, by default.** A project made by `aew init` (with first configuration's `--model`) has everything `RUN` needs, and the operator switches it on with one `aew lead mode raise run`, approved at the operator endpoint (the operator's decision of 2026-11-10: opt-in, not on by default).
- **The standing mode:** the init template writes `steering.mode: crawl`. Absent to crawl is not a raise, so nothing changes until the operator raises it.
- **The notifier:** E104's minimal `aew notify desktop`, which the template writes as `notify.command`. It shows each event as a desktop notification: `notify-send` on Linux, a toast from Windows PowerShell on Windows, with no console window. It shows the event's kind, subject and project, never its reason. With no desktop session it refuses, naming what is missing and both ways back. `--check` reports whether it can show one, and why not. The endpoint passes it the session's own variables (`DISPLAY`, `WAYLAND_DISPLAY`, `DBUS_SESSION_BUS_ADDRESS`, `XDG_RUNTIME_DIR`), which carry no credential. Run's raise and each Run activation refuse the shipped default while it can't deliver (`BOY-12.d`). A command the operator wrote keeps the executable check alone.
- **The endpoint up throughout `RUN`:** the loop asks the endpoint before each auto-run action, not once per activation, so an endpoint lost mid-activation stops the loop (`NOTIFIER_UNAVAILABLE`) before its next step. Restarting a dead endpoint stays a row.
- **`deadline_s`, provisional:** first configuration writes `deadline_s` on the profile it writes, from `first_configuration.DEADLINE_S`.
  - **The measurement, 2026-11-10:** the dogfood workspaces' run results were read for `usage_record.wall_s` only. 42 run result files, 0 run-usage records, so 0 wall times: the runs predate the usage ledger.
  - **So the value is provisional:** the steering envelope's own activation bound, `ENVELOPE_DEFAULTS["loop_deadline_s"]`, derived and not restated: one run should not outlive the unattended activation that started it.
  - **Replaced by:** E117's measured run, with its wall times as the named source. A test pins the value to this note's derivation.
