**M4-E E8b's notifier events.** A run supervisor's `launch_failed` spool line now carries its closed `reason_code` (`schemas/spool-event.schema.json`, `^[a-z_]{1,64}$`), and the notification carries it in `aew/notify-event/v1`'s optional `reason_code`; it is telemetry for the operator and never a relaunch input. The relaunch breaker's opening (control state `recovery.breakers`) is delivered as `breaker_tripped` with `subject: relaunch_breaker`, `ref` the scope and `reason_code` the latest code, once per opening (amendment 1, nit 4: the validation breaker keeps `subject: validation_breaker`). `relaunch_breaker_reset` joins the endpoint's operations, and `recovery breaker reset` the broker's `OPERATOR_ENDPOINT` list. Tests: `tests/unit/test_notify.py::test_event_delivered_once_per_occurrence[breaker_tripped[relaunch],launch_failed[reason_code]]`.
