`aew init` now writes a bundled price table, `src/aew/policy/default_pricing.yaml`, generated by
`tools/pricing_table.py` from OpenCode's model catalog, and the Lead's OpenCode session has `/usage`. Projects made
before this keep no table until the operator adopts one.

**Follow-on, for the weekly triage: exact tier pricing.** `aew/pricing/v1` rows are flat, so a model the catalog prices
higher above a context size holds its base tier and is named in `base_tier_only`, and every figure using it reads "at
least $X; above Nk context costs more". An exact figure needs per-request context sizes in the run-usage record and
tiered rows in the table.
