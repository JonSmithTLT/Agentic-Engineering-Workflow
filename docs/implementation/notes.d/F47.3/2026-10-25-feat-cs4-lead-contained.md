**B4, the Lead contained, is built (STG-05 CS-4, 2026-10-25).** On Linux the operator's one session, `aew opencode`,
runs the Lead's OpenCode TUI in a self-tested `lead` sandbox with a network of its own and a relay per stored provider
login, on a terminal AEW relays; containment is `required` there unless the policy says `allow_weaker`, which runs it
labelled. Windows runs it labelled not contained, as before (F48). The details are on STG-05's note of the same date
and in ADR-0009's amendment of 2026-10-25.
