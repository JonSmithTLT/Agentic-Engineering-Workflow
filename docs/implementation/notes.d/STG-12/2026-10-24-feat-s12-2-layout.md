**S12-2, pull request 5 of 10 (2026-10-24): the control keys (DOC-02) and the layout (DOC-04).**
Two families join the generated reference ([`docs/reference/`](../../../reference/README.md)), 145 records between them
(486 in all).

- **Control keys** ([`control-keys.md`](../../../reference/control-keys.md)): 26 control-state keys and 66 keys of a unit
  in `work`, each a record anchored where the code defines it (a `*_KEY` constant, the initial state, `V2_ONLY_KEYS`, or
  the control schema). The control keys are complete by construction: the control schema is closed
  (`additionalProperties: false`) and validated at every load and commit, and two tree tests hold both. The unit keys are
  the Ticket field registry's inventory joined with the schema's, a lower bound (the unit object is open), none left
  unclassified. The keys `aew init` writes are checked against what `Engine.initialize` really leaves in the store.
- **Layout** ([`layout.md`](../../../reference/layout.md)): 53 records, one per entry of `.aew` (the 14 entries directly
  under it, and every directory above a path the writers family places or the readers read), each with its writers
  (from the writers family) and its readers, whether git ignores it, whether it is the store, and whether a contained
  process sees it. Each flag is derived from its owner (`AEW_GITIGNORE`, `STORE_REL`, the `hide_runs` of the containment
  layout) and checked in a tree test against the thing itself: `git check-ignore`, the engine's own store directory, and
  the layout `for_run` makes. A `.gitignore` line that is not a plain path is refused, not guessed.
- **The readers** are new: 340 read-primitive calls in the tree, found twice (by `ast` and by tokens, sharing no code,
  held equal per module and primitive). 129 are placed under `.aew`, 27 are provably outside it (or read the directory
  itself), and 184 are not placed (the path comes from a parameter, the command line or the environment); those are
  listed on the page by function rather than dropped. A read at import time is refused, as a write is. Both lists are
  lower bounds, and each record points at the writers family's unresolved writes and at the unplaced reads. The
  value-flow evaluator is the writers family's, so a rule of the placement pull request that places more writes may
  place more reads too (not measured).
- **Carried from the review of the roles cut (#258) and its designer's rulings.** The worker-run item is on each path
  record that any CLI command's handler reaches, whatever that command's own role (85 records, not 118; the 28 records
  with no chain and the 5 only a supervisor reaches carry none); the writers page says in its "Not checked" line that a
  write whose destination is not placed carries no role reach and is not checked; the nits N1 (a test that `local/` is
  kept out of git), N2 (a root that is not the CLI's), N3 (a function that writes the store and `local/`) and N5 (the
  wording of the counts).
- **What a change does.** Adding a directory under `.aew` is a decision in `TOP_LEVEL` (writers) and moves the layout page;
  a new `*_KEY` constant naming a state key moves a control-keys anchor. Run `python tools/reference.py render` and
  commit `docs/reference/`.
