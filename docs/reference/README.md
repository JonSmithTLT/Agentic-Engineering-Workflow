# As-built reference (generated)

What the code is, enumerated from the code. It states what the code is, never what it should be, and holds no requirement. Generated by `python tools/reference.py render`; `python tools/reference.py check` regenerates it in memory and fails on any difference, and CI runs it as a fast-lane test. Do not edit these files by hand.

## Files

- [index.json](index.json): the machine index. `records` is keyed by record id (`<family>:<key>`); `counts` measures records per family and per coverage label and the unresolved total, and carries a `digest` of every record and gap; `gaps` is a summary computed from the records, every distinct unresolved item once with its family (nothing lives only there). Schema `aew/reference-index/v1`.
- [entry-points.md](entry-points.md): Entry points
- [gaps.md](gaps.md): Gaps
- [state-machines.md](state-machines.md): State machines
- [writers.md](writers.md): Writers

## A record

- `family`, and `anchor` (`module` and `symbol`; line numbers churn, so a line is never an anchor).
- `basis`: `enumerated` (read from a registry the code owns, at run time), `declared` (a table the generator declares, pinned to the code), `static` (read from the source without running it) or `observed` (read back from something the generator ran).
- `coverage.label`: `complete-by-construction` (names its `registry` and the tests in `check` that stop code bypassing it), `lower-bound` (lists what it could not resolve in `unresolved`) or `unknown`.
- `fact`: the record's own facts.
- `fact_coverage`: on the record, beside `coverage` (it describes facts, so it is not one). For each list fact a detector found, an object keyed by the fact's name, in `coverage`'s vocabulary: how complete the list is. A list fact with no entry is `unknown`, and an empty list never means none.
- A `modules` record also has `imports`, a top-level key: the AEW modules it imports, statically.

## When a change moves it

A pull request that changes enumerated code (a module, its imports, an entry point, a spawn site, a place that writes under `.aew`, a CLI command's handler) runs `python tools/reference.py render` and commits `docs/reference/`. A new directory or file directly under `.aew` is declared first (`TOP_LEVEL` in `tools/reference_families/writers.py`); until it is, its writes are listed as unresolved. After a merge conflict here, take either side and run `render`: the output is a function of the code, so the second change to merge re-renders. Two pull requests that both change the records always conflict, on the `digest` line of `counts`, so a clean merge cannot leave the totals stale.
