# Concurrency

Which locks the code takes, and who works without the control lock. Generated by `python tools/reference.py render`; do not edit. A lock is a record keyed by its `.aew`-relative path, found as a `FileLock` construction (by import source) whose path the value flow places. **Opener** is the function that constructs it; **takers** are the functions that hold it (the opener's callers when it returns the lock, each with the operation name it passes, else the opener itself), with the entry points that reach them and their kinds (from the entry-points family). **Refused in a non-writer** says the opener calls `process_kind.require_writer` before it constructs the lock. The **control lock** is the lock on the path the engine's store owns: its opener is one function, held by a tree test, so that record is complete-by-construction; its takers are a lower bound.

## Works without the control lock

The functions and classes that work without the control lock, and what the code says they may observe: **observes** is the first sentence of the symbol's own docstring, **says** the sentences of the docstring (its own, else its module's) that state it is lock-free; a design citation in either is elided, and a sentence that still names one is left out. The members are the ones `aew.process_kind` names in its module docstring and six this family declares: the compactor's build, re-read and prune, because its module docstring says they run without the lock, and the wake mark's writer, reader and waiter, because the wake signal is advisory (their docstrings say nothing of a lock, so **takes no lock** is the only support there). **Takes no lock** says the static call closure of the member reaches no function that takes a lock; a call this reading does not resolve is not followed.

## What the reading does not see

A lock taken another way than a `FileLock` construction: an in-process `threading` lock or event, SQLite's own locking, a file created with `os.O_EXCL`; a `FileLock` reached under another name (the construction is found by import source, the token reading by spelling, and the two are held to equal counts, so a renamed import fails the agreement test until it is decided); a lock opener or a lock-free member called through a name this reading cannot resolve; and a function that works without the control lock and is neither named by `aew.process_kind` nor declared here. Each is pinned by a probe: an in-process `threading.Lock`, `RLock`, `Condition` or `Event` (the dashboard and the harness have live ones); a file created with `os.O_EXCL` as a guard (the integration queue's checkout sync lock, `checkout_sync_lock_path` in `aew.engine.queue_ops`, is one that serialises a sync across processes); a lock class other than `aew.engine.lock.FileLock`; an opener called through `getattr`; a `FileLock` bound to another name and called by it.
