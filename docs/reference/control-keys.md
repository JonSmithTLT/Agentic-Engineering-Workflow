# Control-state keys

The keys of the control state (`state/control.yaml`), by the code's own name. Generated by `python tools/reference.py render`; do not edit. Each key is a record, `control-keys:<key>` for a top-level key and `control-keys:unit:<key>` for a key of a unit in `work`, anchored where the code defines it: the module-level constant named `*_KEY` that holds it, else the one definition of the keys only a v2 document carries (`aew.engine.base:V2_ONLY_KEYS`), else the function that makes the initial state, else the schema registry (a control key) or the Ticket field registry (a unit key).
