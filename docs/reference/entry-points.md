# Entry points

Every AEW process entry point, from `aew.process_kind.ENTRY_POINTS`: its kind, where it declares itself, and the product sites that start it with `python -m`. Generated by `python tools/reference.py render`; do not edit. A **store writer** takes the engine's control lock; a **non-writer** reads lock-free only and is refused a lock-taking operation before the lock opens. Coverage is complete-by-construction for the set of entry points: the table is the registry, and the tests named in `index.json` stop code bypassing it. `Started by` lists the `-m` forms only; the other ways the CLI is started are in [gaps.md](gaps.md).

### `aew`

- **Kind:** store_writer
- **Why:** the CLI the operator, the Lead and AEW's own workers (the custody worker) run: engine commands take the control lock
- **Declares itself at:** `aew.cli.main:_main`
- **Started by:** `aew.engine.custody_ops:worker_argv`

### `aew (worker run)`

- **Kind:** non_writer
- **Why:** the CLI inside a worker's harness run (AEW_AGENT_ENDPOINT set): `whoami`, `check run` and `submit` go through the run's bridge, whose supervisor holds the credential and the lock; nothing else in that process may take the lock
- **Declares itself at:** `aew.cli.main:_main`
- **Started by:** no `python -m` site in the product

### `aew dashboard serve`

- **Kind:** non_writer
- **Why:** the dashboard server, long-running and read-only: it reads the store lock-free (dashboard.reader) and serializes its own publication with its endpoint lock, never the control lock
- **Declares itself at:** `aew.cli.main:_main`
- **Started by:** no `python -m` site in the product

### `aew lead mcp`

- **Kind:** non_writer
- **Why:** the Lead's MCP transport: it constructs no engine and forwards every call to the Lead broker, which holds the credential
- **Declares itself at:** `aew.cli.main:_main`
- **Started by:** no `python -m` site in the product

### `aew.harness.supervisor`

- **Kind:** store_writer
- **Why:** a run's supervisor: holds the run's credential and commits through the engine
- **Declares itself at:** `aew.harness.supervisor:main`
- **Started by:** `aew.engine.harness_ops:Harness._spawn_run`

### `aew.stg02.server`

- **Kind:** non_writer
- **Why:** the STG-02 slice's producer: it reads a project's committed state lock-free (dashboard.reader) and writes only its own state directory, never the store
- **Declares itself at:** `aew.stg02.server:main`
- **Started by:** no `python -m` site in the product
