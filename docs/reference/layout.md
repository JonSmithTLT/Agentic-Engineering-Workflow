# Layout

The `.aew` directory tree. Generated by `python tools/reference.py render`; do not edit. An entry is a record keyed by its `.aew`-relative prefix (`{}` is a computed segment). **Git-ignored** is what `AEW_GITIGNORE` keeps out of git; the rest git keeps. **Named by** are the module-level constants that are used to build a path (an operand of `/`, a part of an f-string, an argument of `Path`, `os.path.join` or a write primitive) and whose value is exactly the entry; a constant spelled another way, or holding the same text for another purpose, is not found. **Store** is the entry `aew.engine.store.STORE_REL` names and what is under it. **Masked** is an entry the containment layout masks with an empty tmpfs, so what the host keeps there is not seen by a contained process; the run's own scratch, harness and private-git directories under a masked entry are bound back into the mask, writable, and that run sees them (which entries those are is not derived here). **Written by** is from [writers.md](writers.md): the functions that write a path directly in the entry. **Read by** is the functions that read one, by the primitives listed at the end; a read through an API is the API function's, not its callers'.

Both lists are lower bounds. The writes the writers family could not place, and the reads this page could not (below), may touch any entry.

## What the reading does not see

A method named like a read primitive is counted as a read of its receiver, whatever the receiver is (an entry's reader may be a read of something that is not a path), and a read of a path built where it is not used is listed above and not placed. Not seen at all:

- a read by a subprocess
- a method named by a computed attribute, `getattr(path, name)()`
- a primitive bound to a local name and called by it
- a read by a library that opens the path itself (`codecs.open`, `tarfile.open`, `sqlite3.connect`, `zipfile.ZipFile`), and a read through a handle that was opened elsewhere (`fh.read()`)
- a file opened for update, `open(path, 'r+')`: the writers family has it as a write, and it is not counted as a read
- an `open` whose mode is not a literal this reading can read (the writers family lists it as an unresolved write)
- a directory walk, `os.walk`, and the reads by a primitive this reading does not name (`os.fstat`, `os.access`, `os.readlink`, `os.path.lexists`, `os.path.realpath`); the tree has live ones under `.aew` (the store's mode check walks `state`; `control_key` walks `policy`)

The primitives it reads: `Path.exists`, `Path.glob`, `Path.is_dir`, `Path.is_file`, `Path.is_symlink`, `Path.iterdir`, `Path.lstat`, `Path.open`, `Path.read_bytes`, `Path.read_text`, `Path.rglob`, `Path.stat`, `open`, `os.listdir`, `os.lstat`, `os.open`, `os.path.exists`, `os.path.getmtime`, `os.path.getsize`, `os.path.isdir`, `os.path.isfile`, `os.path.islink`, `os.scandir`, `os.stat`, `read_replaced`, `read_yaml`, `sha256_file`, `shutil.copy`, `shutil.copy2`, `shutil.copyfile`, `shutil.copytree`.
