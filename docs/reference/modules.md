# Modules

The import graph of `src/aew`, from the source alone: one record per module (`modules:<module>`), whose `imports` are the AEW modules it imports, in whatever scope the import sits. Generated by `python tools/reference.py render`; do not edit. Nothing is imported to read it, so the graph is static and every record is **lower-bound**: a call that imports by a computed name, or loads code by file path, is a dynamic import this graph cannot follow, and is listed at the end (also in [gaps.md](gaps.md)). `from aew.engine import store` is an edge to `aew.engine.store` when that module exists, else to the package.

**What imports a module:** `python tools/reference.py importers <module>`. The totals: `python tools/reference.py counts`. Neither is on this page, so that a change to one module's imports touches only that module's lines and two pull requests merge.

A group is a second-level package, or `aew` for the top and the modules directly under it.
