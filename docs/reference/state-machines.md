# State machines

The Ticket machine from `aew.engine.transitions` (`RULES`, `STATES`, `TERMINAL`, `PHASE_ORDER`), its guards from the engine's guard table, and the two other state sets the product has a table for. Generated by `python tools/reference.py render`; do not edit. Every edge, state, guard and reason rule has a record. An edge is **lower-bound** when code that changes a Ticket's state without asking the table in the same function can take it (its `coverage.unresolved` names the code); the others are complete-by-construction. What no table lists (a Story's or Epic's phase, a second state tuple) is in [gaps.md](gaps.md).
