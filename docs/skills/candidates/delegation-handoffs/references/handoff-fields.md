# Compact fields for a cold handoff

Use these fields only where the host's existing contract does not supply them. Omit inapplicable detail rather than adding an empty checklist.

**Brief:** goal and reason; scope/non-goals; exact workspace and input revisions/dirty state; governing quotations and locators; required read sections and exclusions; available skill paths/versions; dependencies and current progress; allowed mutations and publisher/communication authority; expected artifact and checks; stop point and unresolved decisions. Name how superseding instructions will be identified.

Keep provenance attached to consequential numbers: decision, measurement (date/environment/units), or snapshot. Make unavailable prerequisites visible. A reviewer needing fresh context should receive the target, contract and evidence, not the author's persuasive narrative.

**Handback:** changed artifact/head identity; checks with commands, environment and outcomes; failure/ablation evidence; CI head/run/attempt observation where applicable; remaining risks/questions; whether each major claim was executed, inspected or inferred. Give enough locators to reproduce a result without dumping logs into the brief.

**Feedback:** missing inputs; wrong/stale facts; noise; candidate reusable rule; skill path/version actually loaded; one instruction that changed behavior; one gap; whether to load again and why. Keep feedback optional when the host does not request it; never invent a worker's experience. Collect in the existing feedback location, and separate task-specific facts from reusable technique.

**Relay check:** validate the specific claim on which the next action relies. For a complete inventory, inspect method and limits; for a test claim, inspect actual scope/skips; for CI, observe the exact head/attempt; for an absence claim, challenge alternate consumers. Label unverified remainder as reported evidence. Preserve original reports and corrective updates.
