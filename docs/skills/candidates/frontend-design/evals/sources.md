# Research and selection

Evaluator-only; inspected 2026-10-12. This is an original synthesis of selected current primary sources, not a measured ranking of the market. Live links can change; freeze runtime bytes and source snapshots for any comparative pilot. External skills and their installers were not executed.

| Primary source | Retained principle | Deliberately excluded |
|---|---|---|
| [Anthropic frontend-design](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md) | Subject-specific art direction and deliberate hierarchy. | Persona inflation, mandatory confirmation, and universal trend bans. |
| [Impeccable](https://github.com/pbakaus/impeccable/blob/main/plugin/skills/impeccable/SKILL.md) and [new work](https://github.com/pbakaus/impeccable/blob/main/skill/reference/new-work.md) | Different surface purposes; preserve existing identity for refinement; brief takes precedence over aesthetic heuristics. | Launcher/download dependency, command suite, absolute style bans, fixed verification ceiling. |
| [UI Skills improve-ui](https://github.com/ibelick/ui-skills/blob/main/skills/improve-ui/SKILL.md) | Evidence from the existing interface before recommending changes. | Its read-only audit role and mandatory report destination as universal constraints. |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md) | Detect project stack; resolve the actual interaction concern; load specialized guidance only when relevant. | Catalog/database/search dependency, generated style recipes, universal numeric defaults. |
| [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) | Native semantics, visible focus, recoverable forms, reduced motion, content variation and media sizing. | Mandatory live fetching, house copy style, unconditional URL synchronization and fixed list-size thresholds. |
| [W3C modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) | Focus ownership, accessible naming, and real modal behavior. | Treating an ARIA attribute or screenshot as proof of accessibility. |
| [W3C reflow guidance](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | Content remains usable under narrow/reflow conditions, with meaningful exceptions for two-dimensional data. | Hiding essential overflowing content to make a screenshot appear clean. |

The worker-facing core and references are newly authored. The former Anthropic entrypoint is replaced at the same candidate path; the existing Apache license is retained. Source provenance stays here rather than expanding worker context. This replacement is not a production-loader migration.
