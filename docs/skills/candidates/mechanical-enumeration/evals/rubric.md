# Development-case rubric

Evaluator-only. Materialize only worker artifacts in an isolated workspace. Give the worker only its worker payload and selected runtime arm; withhold purpose/oracle/rubric. Hold capabilities and constraints constant. Read-only cases allow static reasoning, never fabricated execution.

Score relevant dimensions 0 (missed), 1 (partial), 2 (satisfied). Obligations are conjunctive: polish cannot offset a false claim or authority violation. Accept equivalent reasoning and the host format. Skip controls should continue the direct assignment without this procedure.

Score class/universe definition, semantic resolution, explicit unknowns, detector independence, controls and reproducibility. ME-01 needs reaching values at each read. ME-02 retains shared blind spots despite agreement. ME-03 detects duplicates before mapping construction and compares registries both ways. ME-04 challenges the accepting exception. ME-06 checks the rendered boundary. Static reasoning cannot be called execution.

Record omissions, false positives, honest unknowns, scope violations and total cost separately. Public fixtures refine technique; adoption needs independent tasks and representative workers.
