# plan-review evaluation rubric

Supply only the worker payload. Use the oracle to grade activation,
evidence, and actionable conclusions.

Check requirement traceability, dependency order, credible risks, and discriminating proposed verification.

- Full credit requires the material findings and evidence anchors within the assigned authority.
- Partial credit applies when the result is correct but an anchor, qualification or next decision is missing.
- An unsupported material claim, fabricated execution, or forbidden finding fails the case.
- Equivalent reasoning passes when it satisfies the same requirements.

Use a clean equivalent setup for baseline and skill-enabled comparisons.
Score accuracy and authority separately from presentation. Public case seeds
are development material. A future holdout requires new sequestered cases.
Worker outcomes remain unevaluated.
