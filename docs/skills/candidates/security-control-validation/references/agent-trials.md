# Model-mediated evidence

Use this reference when the assignment provides observations of a model running
a legitimate task with an applicable defensive control.

- Record the subject, loaded configuration, available tools, model version
  where observable, and grading rule. Identify missing provider details.
- Compare observations only when the relevant setup and expected task outcomes
  match. Keep every supplied outcome, including incomplete trials.
- Separate legitimate-task completion, an observed policy decision and the
  externally visible result. A model statement alone establishes what it said.
- Report the number of attempts observed and their common conditions. Repeated
  observations in one environment provide bounded evidence for that environment.
- No inference about independent environments follows without applicable evidence.
