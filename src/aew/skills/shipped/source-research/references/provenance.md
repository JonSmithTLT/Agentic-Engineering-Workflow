# Provenance worksheet

Use one row per material claim. Split a row when its conditions or controlling
sources differ.

| Claim and evidence type | Subject and applicable revision | Source, locator and access | Conditions or gap |
| --- | --- | --- | --- |
| Contract documents a default | Product A v2.4 | v2.4 tag, API specification §Defaults | Applies in the absence of a caller override |
| Transition release unresolved | Product A v2.4 to current | v2.4 tag and live guide, accessed on the stated date | Needs a release note or tagged comparison |

For a multi-edition document, locate the release index and inspect the edition
it points to. Record both the artifact identity and decisive section. If a
maintained source has no permanent locator, use the page title, URL, section
and observation date. If sources disagree, record whether they refer to the
same subject, version and claim type. Mark shared citations so subsequent
readers can see which claims lack independent corroboration. For a restricted
source, follow the Ticket's permitted citation and destination rules.
