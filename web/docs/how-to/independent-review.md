# Independent frontend review

Agree the exact committed runtime tree, provisional contract digest, evidence bundle and task before review. Rebuild with the [pinned gate](verification.md) or explicitly disclose a reproduction limitation. Inspect the compiled desktop and phone product using only its UI; source inspection and developer tools cannot substitute for completing the investigation.

Record IDs, navigation steps, supplied outcomes, limitations, citations, keyboard/focus behavior and usability failures. Check both themes, narrow layouts and zoom where relevant. Distinguish preparation, delivery acknowledgment, citation and evaluated benefit; inspect supplied relations without inferring causality or completeness.

Use the [task review template](../templates/task-review.md). A finding needs reproduction steps, expected/observed behavior, severity and source identity. Re-review corrections against their actual committed build. Keep reviewer disposition separate from operator approval, CI, merge state and backend adoption. Do not silently rewrite the original review after a fix; append or issue a dated re-check.
